# Dauphin County, PA — Child Care / Family Support Audit Pilot
Date started: 2026-10-25 — AUDIT COMPLETE AS A STAGED FILE, NOT SENT.
Scope: child care centres, Pre-K / Head Start, Early Learning Resource
Center (ELRC) / Child Care Works subsidy route, early intervention
(birth–3), family centres, and after-school / family support serving
Dauphin County (the Harrisburg area), Pennsylvania. This file is the
candidate list from public directories; findings are in
audit-report-2026-10-25.md (same folder). Nothing has been sent to
statewide PA 211 or any organisation, and no organisation was contacted.

## Rules applied to this list
- No organisation, PA 211, or anyone else was contacted.
- Own site beats directory. Directory beats a third-party aggregator.
- A failed, missing, or lapsed page is UNVERIFIED, never a closure finding.
- Audit contact information only: name, phone, address IF public, ages
  served, subsidy/assistance route IF stated on own site, hours,
  waitlist status IF stated on own site. Do NOT rewrite child care,
  health, or benefits advice. Do NOT record any information about
  individual children, and no children's personal information or photos
  appear in this audit.
- Large multi-site providers are counted once as an organisation where
  stated (Aa to Zz, Hansel & Gretel, KinderCare sites are listed
  separately because each has its own address/phone in the directory
  and on KinderCare's own finder; do not merge them).
- ZIP code does not settle county — exact address / township does.
  Several Harrisburg-area listings are in Cumberland County and are
  listed at the end as OUT OF SCOPE, not counted as Dauphin.
- Keith is NOT described as a local resident of Dauphin County.

## Anchor sources
- search.pa211.org / pa211.org (statewide PA 211 database — NOT
  PA 211 East, NOT the Lancaster database manager). Note: a direct
  site:search.pa211.org search returned no indexed Dauphin child-care
  records on 2026-10-25, so the pilot was built from PA 211's
  directory context plus the secondary lists below, and every item
  was then checked against the organisation's own site/page.
- Public secondary lists / place directories (Harrisburg-area centre
  lists, PA Pre-K provider list, licence records on childcarecenter.us)
- Individual organisations' own websites (checked per item; see audit
  report for which checks were full page fetches and which were
  search-indexed own pages — see the method limit note there)

## Excluded from this audit (different category, for later)
- K-12 schools and school-district Pre-K run inside a school
  building (unless listed as a PA 211 child care listing) — not
  counted here, except where a YMCA SACC programme operates in a
  school (#25, flagged as school-site care).
- Commercial tutoring / music / sports programmes for children —
  out of scope.
- Family medical practices and Children & Youth protective
  services (e.g. Dauphin County Children & Youth, 1001 N 6th St,
  (717) 780-7200) — related family services, not child care /
  family support as listed here; noted only to avoid merging
  them into this category.
