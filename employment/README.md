# Dauphin County, PA — Employment Help Listing Audit

**Checked: 2026-10-25. Status: staged only, NOT SENT. Nothing in this
audit has been sent to PA 211 or any organisation.**

## What this is
A small, dated audit of 25 employment-help listings serving Dauphin
County, PA (Harrisburg area), checked against the organisations' own
websites and other public listings. It is a curation audit, not a
replacement directory: it does not claim to be a current list of open
services, and it should not be used as one without checking with the
organisation or PA 211 first.

## Method and limits — please read before using this
- Public web search and page-text fetch only, 2026-10-25. No
  organisation, PA 211, or anyone else was contacted for this audit.
- An organisation's own website is treated as authoritative over
  third-party directories; the statewide PA 211 database
  (pa211.org / search.pa211.org) is the directory — NOT PA 211 East
  and NOT the Lancaster database manager.
- **No organisation is called defunct or closed in this audit.** A
  failed or missing page is reported as unverified, never as closure.
- AARP SCSEP Harrisburg, CEEED, Catholic Charities employment
  placement, Easterseals Harrisburg, and Merakey Harrisburg are
  UNVERIFIED from own sites — evidence gaps, not closure findings.
- ZIP code does not settle county; Camp Hill, Carlisle, Enola, and
  Lancaster addresses were checked by exact address.
- This audit was prepared with AI assistance. Corrections,
  challenges, and updates from PA 211 or the organisations
  themselves are welcome — that is the point of publishing it
  here first. This audit does not refer to Keith as a local
  resident of Dauphin County.
