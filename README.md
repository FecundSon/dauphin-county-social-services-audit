# Dauphin County, PA — Social Services Listing Audits

**All categories checked: 2026-10-25. Status: staged for publication in
Keith's own repo first. Nothing in this audit has been sent to PA 211
or any organisation as a direct message.**

## What this is
One county, twelve public categories — a dated curation audit of
public social-services listings for Dauphin County, PA (Harrisburg
area), checked against the organisations' own websites and other
public listings. It is not a replacement directory: it does not claim
to be a current list of open services, and it should not be used as
one without checking with the organisation or PA 211 first.

Each category folder holds three files: a README with the headline
corrections, the full audit report with evidence and sources, and the
original pilot list it was checked against.

## Method and limits — please read before using this
- Public web search and page-text fetch only, 2026-10-25. No
  organisation, PA 211, or anyone else was contacted for these audits.
- An organisation's own website is treated as authoritative over
  third-party directories.
- **No service is called defunct or closed in these audits.** A failed
  or missing page is reported as unverified, never as closure.
- Fares, schedules, waitlists, funding windows, and seasonal dates are
  date-stamped to 2026-10-25 and must not be presented as permanent.
- For mental health, substance use, and legal aid, contact information
  only was audited — no advice was rewritten.
- **Re-checks needed before any outward send:** several page-text
  fetches hit a 429 rate limit during checking and were not retried;
  affected details are marked UNVERIFIED or CLARIFIED in the reports,
  not guessed. Before sending, re-check the items each report flags
  (notably: food pantries — a live-browser check of search.pa211.org
  for Dauphin County, since PA 211's search pages are JavaScript-driven
  and a text fetch did not return a complete result list; transportation
  — rabbittransit MATP/shared-ride, Greyhound, and Trailways pages;
  mental health — Merakey, PPI moved locations, and the county mental
  health programme page; shelters — Bethesda women/children address,
  Salvation Army shelter programme, CCU overnight-shelter season, and
  Shalom House's current domain; seniors — the county centre count
  and ombudsman intake number; disability — ODHH, Merakey/CSG sites,
  and the SSA locator).
- These audits were prepared with AI assistance. Corrections,
  challenges, and updates from PA 211 or the organisations themselves
  are welcome — that is the point of publishing them here first.

## Recipient note
Dauphin County listings live in the **statewide PA 211 database**
(pa211.org / search.pa211.org), not with PA 211 East (a United Way of
Lancaster County programme serving Berks and Lancaster). Dauphin
corrections go to statewide PA 211, via a vetted direct contact where
one can be found, with a form as fallback only.
