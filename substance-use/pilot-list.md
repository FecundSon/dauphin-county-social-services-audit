# Dauphin County, PA — Substance Use Treatment / Recovery Audit Pilot
Date started: 2026-10-25 — AUDIT COMPLETE, NOT SENT.
Scope: substance use treatment / recovery listings serving Dauphin County
(Harrisburg area), Pennsylvania.
This file is the candidate list from public directories; findings are in
audit-report-2026-10-25.md (same folder). Nothing has been sent to PA 211
or any organisation. Nothing in this audit is treatment or medical advice;
it audits contact information only. No bed/placement availability is
reported as a fact; intake process only. No organisation is called
closed/defunct from a failed page load; such items are UNVERIFIED.
Keith is NOT a local resident of Dauphin County and is not described as
one anywhere in this audit.

## Rules applied to this list
- No organisation, PA 211, or anyone else was contacted.
- Own site beats directory. Directory beats a third-party aggregator.
- ZIP code does not settle county — exact address does. Lemoyne, Camp
  Hill and Mechanicsburg are Cumberland County; Elizabethtown is
  Lancaster County; Palmyra and Lebanon are Lebanon County. Those are
  OUT OF SCOPE for a Dauphin list even when a regional directory groups
  them under "Harrisburg area."
- Do NOT publish a domestic-violence safe-house address, even if found
  in a directory (none expected in this category).
