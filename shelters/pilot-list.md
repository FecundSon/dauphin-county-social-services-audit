## Rules applied to this list
- No shelter, PA 211, or anyone else was contacted.
- No bed availability is reported as a static fact anywhere in this audit; intake phone/process only.
- DOMESTIC VIOLENCE / CONFIDENTIAL LOCATIONS: no safe-house address is published, repeated, or stored in these files, even if a directory lists one. DV listings record helpline numbers and public services only. If confidentiality is unclear, treat the location as confidential. Confidential-location flags in this audit: 1 (by count only; no address written for it).
- No claim that a shelter is closed/defunct is made from a failed page load; such items are UNVERIFIED.
- Seasonal shelters: dates are stated only where an organisation's own site states them; a winter-only shelter is never presented as year-round.
- ZIP code does not settle county — exact-address location does. Harrisburg-area names and "Capital Region" coverage do not settle Dauphin County either.
